# 🪄 Unity 角色控制和武器系统 (Player And Weapon)

这是一个基于 Unity 制作的角色控制系统和法杖武器系统（武器脚本挂靠在角色上）组件。代码和预制体分离
## 📦 包含内容
- 角色预制体 (Prefab)
- 相关的 C# 控制脚本
- 完整的 .meta 依赖文件

## 🛠️ 如何在你的项目中使用

1. 点击网页右上角的绿色的 `Code` 按钮，选择 **Download ZIP** 下载全部文件。
2. 解压压缩包。
3. 打开你自己的 Unity 工程，将解压出的整个文件夹拖拽到你项目的 `Assets` 目录中。
4. 在 Unity 的 Project 窗口找到预制体（`.prefab`），直接拖入游戏场景（Hierarchy）即可使用。
5. （可选）如果你有特定的配置需求，可以在 Inspector 面板中调整脚本的参数。

## ⚙️ 环境要求
- **Unity 版本**：推荐使用 202.3.62或更高版本

## 🎮 功能特点
- **功能1**：*(wasd控制移动，鼠标左键控制射击)*
- **功能2**：*(射击跟随准星)*
- **功能3**：*(shift冲刺，空格保持失重状态)*

- **武器功能1**：*(武器拥有多个存储能量的圆盘，圆盘上有多个能量槽(参数可修改))*
- **武器功能2**：*(按q切换圆盘，按右键释放能量搭配产生的技能)*
